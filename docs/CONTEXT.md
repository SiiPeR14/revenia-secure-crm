# Contexto conservado

La carpeta `docs/context` contiene los tres textos entregados por el propietario y el historial recuperado de la conversación “Prompt para SaaS CRM”. La carpeta `docs/references` conserva las cinco imágenes que definen la dirección visual inicial.

## Referencias visuales

1. `01-precios.png`: planes y servicios adicionales.
2. `02-panel-propietario.png`: administración global de Revenia.
3. `03-dashboard-cliente.png`: panel del cliente y Recovery Center.
4. `04-facturas.png`: facturas e importaciones.
5. `05-mapa-pantallas.png`: mapa de las nueve áreas iniciales.

Estas referencias guían el diseño. No se interpretan como evidencia de que todos los módulos representados estén implementados.
